# ADR-001 Monorepo 工具链

## 元数据（Metadata）

- 状态：Accepted
- 关联架构章节：2. 当前仓库拓扑（实现事实）；9. 当前已知约束与缺口

## 架构对齐（Architecture Alignment）

本 ADR 对上述相关架构章节具有规范性约束作用。

## 背景（Context）

需要在同一仓库管理 web、electron、server 与 shared，并保证安装/构建/测试性能。

## 决策（Decision）

1. 使用 `pnpm` 作为包管理器。
2. 使用 `pnpm-workspace.yaml` 定义工作区边界。
3. 使用 `turbo` 做任务编排与缓存。

## 备选方案（Alternatives）

1. 仅使用 npm workspaces：迁移简单但缓存与性能能力弱。
2. 使用 nx：能力强但引入成本更高。

## 影响（Consequences）

正向影响：
1. 依赖安装更快，磁盘占用更低。
2. 跨包任务执行一致。
3. CI 缓存命中率提高。

负向影响：
1. 团队需要掌握 pnpm/turbo 约定。
2. 必须严格维护包边界。

## 回退触发条件（Rollback Triggers）

1. CI 性能持续不达标且无法缓解。
2. 工具链造成持续交付阻塞。
