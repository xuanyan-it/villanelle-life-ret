# ADR-012 幂等与错误语义基线

## 元数据（Metadata）

- 状态：Accepted
- 关联架构章节：3. 运行模式与集成；4. 传输与认证语义；8. 测试分层（当前）

## 架构对齐（Architecture Alignment）

本 ADR 对上述相关架构章节具有规范性约束作用。

## 背景（Context）

Web HTTP 与 Electron IPC 并行运行时，若错误结构和客户端可见语义不一致，会导致前端分支逻辑膨胀和回归困难。  
当前基线采用统一 envelope 与安全错误消息机制，并明确不引入请求级幂等键。

## 决策（Decision）

1. 统一响应 envelope 结构：`code/status/payload/meta/message`，由 shared helper 生成。
2. 统一安全错误语义：仅允许共享白名单错误文本透出，其余错误统一回退为安全消息。
3. 当前不启用 `idempotencyKey` 协议，create/delete 语义按现有业务实现执行。
4. delete 接口当前为“执行结果语义”，当底层返回失败时返回冲突错误，而非强制幂等成功。

## 备选方案（Alternatives）

1. 各端自行定义 envelope 与错误文本：实现快但长期漂移风险高。

## 影响（Consequences）

正向影响：
1. 前后端错误处理逻辑更稳定。
2. 跨传输（HTTP/IPC）契约一致，回归成本更低。

负向影响：
1. 缺少请求级幂等键时，重复提交保护依赖业务层约束。
2. delete 非强幂等语义在重试场景下由客户端承担补偿处理。

## 回退触发条件（Rollback Triggers）

1. 错误语义策略被新的跨端契约基线替代。
