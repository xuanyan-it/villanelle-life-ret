# ADR-006 数据库迁移策略

## 元数据（Metadata）

- 状态：Accepted
- 关联架构章节：5. 数据与持久化；9. 当前已知约束与缺口

## 架构对齐（Architecture Alignment）

本 ADR 对上述相关架构章节具有规范性约束作用。

## 背景（Context）

数据库变更若无策略，容易造成不可回滚故障。

## 决策（Decision）

1. 仅允许版本化 migration。
2. 当前迁移工具链基于 `drizzle-kit`（`db:generate` / `db:migrate`）。
3. 发布窗口内执行迁移并明确回滚边界；禁止生产自动建表。
4. 生产环境不提供自动 DDL 的 env 逃生门，schema 变更统一走 migration 流程。

## 备选方案（Alternatives）

1. 运行时自动同步 schema：方便但高风险。

## 影响（Consequences）

正向影响：
1. 变更可审计。
2. 回滚边界清晰。

负向影响：
1. 迁移脚本维护成本上升。

## 回退触发条件（Rollback Triggers）

1. 迁移策略持续无法满足交付效率且经评审批准替代方案。
