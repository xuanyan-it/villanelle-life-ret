# ADR-014 数据库暴露面与测试环境安全基线

## 元数据（Metadata）

- 状态：Accepted
- 关联架构章节：3. 全局强约束；7. 当前关键风险；`docs/docker-deploy.md`

## 架构对齐（Architecture Alignment）

本 ADR 对上述相关架构章节与部署说明具有规范性约束作用，并与 ADR-009（运维安全与可观测性）、ADR-004（持久化拓扑）互补：ADR-004 定义**用何种数据库**，本 ADR 定义**数据库在任何可达网络上的暴露与认证基线**。

## 背景（Context）

测试或联调用的 PostgreSQL 若绑定公网（如 `0.0.0.0:<端口>`）且使用默认或易猜口令，会被自动化扫描批量攻破；攻击者可在取得会话后于容器或主机侧落地恶意程序（例如伪装为 `/tmp/mysql`、配套 `/tmp/init` 等驻留）。此类风险与业务代码缺陷无关，属于**暴露面与运维基线**问题，需在架构与部署文档中显式禁止并纳入巡检。

## 决策（Decision）

1. **主栈数据库默认不暴露公网**：仓库根目录 `docker-compose.yml` 中的 `db` 服务承载业务 API 所用 Postgres，**不得**增加将容器 `5432` 映射到公网（含 `0.0.0.0`）的 `ports`；仅走 Docker 内部网络供 `api` / `api-migrate` 访问。若本地开发必须宿主机访问，应绑定 `127.0.0.1:<端口>`，而非全网卡。
2. **禁止弱口令与多环境口令复用**：禁止在生产、主测试库或任何公网可达实例上使用 `postgres/postgres` 或等价默认组合；CI/E2E 使用的 `E2E_DATABASE_URL` 等须为**仅此用途**生成的高熵口令，与生产及人机共用密码、与 compose 主库 `POSTGRES_PASSWORD` **隔离**。
3. **E2E 专用库的「公网端口」例外（可接受但须满足以下全部条件）**  
   团队若因自动化 E2E（如 GitHub Actions、外网 Runner）必须让**单独部署**的 Postgres 监听公网端口（例如宿主机 `15432` 映射容器 `5432`），视为受控例外，**不是**主 compose `db` 的对外端口；**必须与**主测试环境业务库（通常在 compose 内、不映射公网）**实例级隔离**（独立容器/独立数据目录/独立口令）。须同时满足：  
   - 仅存放自动化测试数据，无生产或须保护的正式业务数据；  
   - 口令为长随机、专用于该实例，并建立轮换与泄露应急替换流程；  
   - **认知**：更换端口号不提供隐匿性，全端口扫描仍会发现服务；强口令可显著提高撞库成本，但不能替代网络层收缩。  
   **优先补偿**：在可行时，对 `15432`（或等价端口）在安全组/firewall 上做**来源 IP 限制**（例如固定出口的自托管 Runner、办公网 VPN 网段）；GitHub 托管 Runner 出口 IP 多变时，可评估自托管 Runner、`actions` 与云厂商 IP 列表、或改为 **SSH/VPN 隧道/Warp** 连内网库等方案，减少对 `0.0.0.0/0` 开放数据库的依赖。  
4. **云侧网络默认最小开放**：除经书面评审的 E2E 例外端口外，安全组/防火墙尽量不对数据库端口做全球可访问；业务仍仅开放 80/443 等必需端口。  
5. **入侵征兆自检（运维例行）**：异常高 CPU、容器内 `/tmp/` 下非预期可执行文件或冒充系统名进程（如可疑 `mysql`）、陌生 PostgreSQL 客户端 IP 会话，须按安全事件流程排查，而非仅当作应用性能问题。

## 备选方案（Alternatives）

1. 测试库对公网开放但仅依赖「非默认端口」而无强口令或实例隔离：**不可取**（与 2026-03 事件同型风险）。  
2. 仅口头约定强口令与「15432 与 5432 不同」：**不足**；须在架构文档与部署清单中可核对（哪一实例可公网、哪一实例仅内部）。  
3. **更优**：E2E 数据库只监听内网 + VPN/隧道/自托管 Runner 同 VPC，从架构上取消对公网 `5432` 系端口的依赖。

## 影响（Consequences）

正向影响：

1. 与 `架构事实与约束.md`、`docker-deploy.md` 形成一致表述，避免「文档 say A、现场配成 B」。

负向影响：

1. 完全内网化 E2E 数据库时，CI 网络方案略复杂；若保留公网 E2E 端口，需持续承担暴力尝试与未补丁漏洞面的残余风险，依赖口令熵、隔离与监控补偿。

## 回退触发条件（Rollback Triggers）

1. 产品正式取消一切云侧自建 Postgres，且替代方案的安全模型经评审书面确认（届时可 Superseded 本 ADR 并指向新 ADR）。
