# ADR-010 交付流水线与发布治理

## 元数据（Metadata）

- 状态：Accepted
- 关联架构章节：9. 当前已知约束与缺口；10. 关联文档

## 架构对齐（Architecture Alignment）

本 ADR 对上述相关架构章节具有规范性约束作用。

## 背景（Context）

需建立可重复、可追踪的交付流程与回滚机制。

## 决策（Decision）

1. 仓库提供统一的构建、测试与 E2E 命令入口，发布校验以实际命令结果为准。
2. 服务端发布采用 migration 驱动，禁止运行时自动 schema 同步。

## 备选方案（Alternatives）

1. 仅人工发布清单：灵活但一致性和审计弱。

## 影响（Consequences）

正向影响：
1. 发布可追踪。
2. 问题定位速度提升。

负向影响：
1. 流水线维护成本增加。

## 回退触发条件（Rollback Triggers）

1. 交付平台变更并通过新 ADR 替代。
